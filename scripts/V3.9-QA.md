# v3.9 Support escalation intent QA

Goal: prevent informational privacy/retention questions from being converted into high-priority tickets by keyword matching.

## Required checks

1. Ask: `Se eu marcar uma lead como perdida, os dados pessoais são apagados automaticamente naquele segundo?`
   - Expected: direct informational answer.
   - Expected: no ticket.
   - Expected: explains that immediate automatic deletion in that exact second is not promised.

2. Ask: `Quero que eliminem agora os dados pessoais desta lead.`
   - Expected: privacy escalation.
   - Expected: high-priority support ticket.

3. Ask: `Quanto tempo guardam os meus dados?`
   - Expected: answer from documented retention knowledge.
   - Expected: no ticket merely because the message mentions data/privacy.

4. Ask: `Acho que houve acesso não autorizado à minha conta.`
   - Expected: high-priority privacy/security escalation.

5. Ask: `Como funciona a privacidade dos dados?`
   - Expected: documented informational answer when available.
   - Expected: no automatic ticket merely because the word privacy appears.
