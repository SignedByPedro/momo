# Momo v3.8 - Support lead-retention clarification

## Purpose
Prevent Momo Support from creating a ticket merely because a client asks whether marking a lead as lost deletes personal data immediately.

## Expected policy answer
- New/contacted leads may be kept while commercially relevant.
- After a lead is lost or converted, personal lead data is no longer needed as a commercial lead and should be removed through the applicable process.
- Do not promise that marking a lead lost performs guaranteed automatic deletion in that exact second unless current product behaviour explicitly confirms it.
- A question about that timing is informational and should not create a ticket.
- An explicit request to delete personal data now, or a concrete deletion failure requiring intervention, may be escalated as a privacy request.

## Apply
1. Run `supabase/v3.8-support-lead-retention-clarification.sql`.
2. Reindex Momo Support Knowledge Base.
3. Run `node scripts/test-v308-support-lead-retention.mjs`.
4. Re-test in the Portal as Owner or Member:
   - `Se eu marcar uma lead como perdida, os dados pessoais são apagados automaticamente naquele segundo?`
   - Expected: direct policy answer, no ticket.
   - `Quero que eliminem agora os dados pessoais desta lead.`
   - Expected: privacy escalation/ticket, because this is an actual deletion request.
