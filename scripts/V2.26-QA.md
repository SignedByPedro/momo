# Momo v2.26 — Compact conversation URLs

Only the **display** is shortened. Keep the complete original website address,
including query parameters and fragments, in the database and in all AI analysis.
This update does not require a Supabase migration.

1. In Admin > Conversas, open an existing sales conversation with a long JYSK
   or Samsung marketing URL. The conversation card should show a short domain
   and meaningful pathname, without the advertising query. The URL must not
   extend beyond the card, even on mobile.
2. Open that conversation. In the Context > Website area, click the compact
   link. It must open the full original URL, including query parameters.
3. Open an Admin sales conversation, an Admin client conversation and a Portal
   client conversation with an ordinary text message containing a very long
   HTTP(S) URL. The message must fit its bubble, with a compact clickable link.
4. If a user provides a URL such as `https://shop.example.com/search?q=sofa`,
   verify that the clickable destination still contains `?q=sofa`.
5. Older conversations must display compactly without changing their stored
   messages or website information. No user-facing AI response wording changes.

Validation:

```powershell
node scripts/test-v226-conversation-links.mjs
npm run lint
npx tsc --noEmit
npm run build
```

Deploy only when all commands pass.
