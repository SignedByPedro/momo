# Momo v3.6 - Support Structured Output QA

Goal: remove intermittent generic fallback replies caused by malformed model JSON.

## Automated
Run:

```powershell
node scripts/test-v306-support-structured-output.mjs
npm run lint
npx tsc --noEmit
npm run build
```

## Manual regression
In Momo Support, ask the following several times in mixed order:

1. Como comparo os tons?
2. Mudar o tom muda os factos que o agente pode dizer?
3. Quais são os modos de captação de contactos?
4. How do I compare the agent tones?
5. What are the contact capture modes?

Expected:
- No generic "couldn't fully process" / "não consegui processar" response.
- Answer language follows the latest clear PT/EN user message.
- Authenticated Owner/Member permissions remain authoritative.
- No ticket is created for these normal how-to questions.

## Why
The primary model call now uses AI SDK schema-enforced structured output. A text-JSON retry remains only as a defensive fallback if the structured call itself fails.
