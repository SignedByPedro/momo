# Momo v2.33 - QA

## Installation

1. Run `supabase/v2.33-knowledge-foundation.sql`.
2. In Admin > Conhecimento do Momo, click `Reindexar conhecimento`.
3. In Admin > Support > Knowledge Base, click `Reindexar documentação`.
4. Run `supabase/v2.33-readonly-knowledge-verification.sql` and confirm every result is `true`.
5. Run `node scripts/test-v233-knowledge-foundation.mjs`.

## Sales questions

Test Momo with questions such as:

- `Preciso de ter website para usar o Momo?`
- `Quantas línguas estão incluídas no plano base?`
- `Posso adicionar Inglês mais tarde?`
- `O cliente consegue mudar o idioma principal sozinho?`
- `O que consigo personalizar no widget?`
- `Tenho acesso às conversas e leads?`
- `Vocês têm integração pronta com o meu CRM?`
- `Quanto custa?`

Expected behaviour: factual product answers from the new knowledge, no invented integration/pricing commitments, and natural sales follow-up when appropriate.

## Support questions

Test Momo Support with:

- `Como mudo o idioma principal?`
- `Como adiciono inglês ao meu agente?`
- `Qual é a diferença entre Owner e Member?`
- `Posso remover outro Owner?`
- `Como elimino a minha própria conta?`
- `Sou o último Owner, consigo apagar a minha conta?`
- `Como comparo os tons do agente?`
- `Qual é o tamanho mínimo e máximo do widget?`
- `O link aparece encurtado nas conversas. Perdi parte do URL?`
- `Posso marcar um ticket como resolvido?`
- `Porque aparece um aviso no Support?`
- `O login devia manter-se depois de refresh?`
- `Como exporto os dados da empresa?`
- `Se cancelar o serviço os dados são logo apagados?`
- `Qual é o prazo de resposta de um humano?`

Expected behaviour: solve documented how-to questions directly, distinguish actions that require the Momo team, and never invent SLA or commercial terms.
