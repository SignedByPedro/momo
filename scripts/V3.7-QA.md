# Momo v3.7 - Plain Support Messages QA

Goal: keep Momo Support conversational and prevent raw Markdown markers from reaching the Portal chat.

## Automated

```powershell
node scripts/test-v307-support-plain-text.mjs
npm run lint
npx tsc --noEmit
npm run build
```

## Manual checks

Ask Momo Support:

1. `Como comparo os tons?`
2. `Quais são os modos de captação de contactos?`
3. `What are the contact capture modes?`

Expected:

- No `*` or `**` around labels or option names.
- No Markdown headings, backticks or Markdown-style links.
- Plain, natural chat text.
- Short lists may still use simple numbered/plain lines when useful.
- Existing role awareness, multilingual support and ticket escalation remain unchanged.
