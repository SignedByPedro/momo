# Momo v2.34 - QA

## Installation

1. If v2.33 has not already been applied, run `supabase/v2.33-knowledge-foundation.sql` first.
2. Run `supabase/v2.34-business-policies-knowledge.sql`.
3. In Admin > Conhecimento do Momo, click `Reindexar conhecimento`.
4. In Admin > Support > Knowledge Base, click `Reindexar documentação`.
5. Run `supabase/v2.34-readonly-business-policies-verification.sql` and confirm every result is `true`.
6. Run `node scripts/test-v234-business-knowledge.mjs`.
7. Run the normal lint, TypeScript and build checks before deployment.

## Sales questions

Test Momo Sales with:

- `Quanto tempo demora a implementação?`
- `O que inclui o plano base?`
- `Quando começa a mensalidade?`
- `O que acontece se um pagamento falhar?`
- `Existe fidelização?`
- `Se cancelar hoje perco logo o serviço?`
- `Recomendam quanto tempo para testar o Momo?`
- `Vocês fazem gestão de encomendas?`
- `Integram com Primavera?`
- `Qual é o vosso uptime garantido?`
- `A IA pode dar uma resposta errada?`

Expected: factual answers only from approved knowledge. Onboarding should remain simply case by case. Unconfirmed features/integrations must not be presented as available. Exact prices must not be invented.

## Support questions

Test Momo Support with:

- `Não tenho acesso ao código do site. Como instalo o widget?`
- `Quando começa a mensalidade?`
- `Falhou o pagamento. O Portal também fica bloqueado?`
- `Quero cancelar. Até quando funciona?`
- `Quanto tempo guardam as conversas?`
- `Se pedir eliminação tenho de esperar 90 dias?`
- `Quando apagam dos backups?`
- `Qual é o prazo de resposta da equipa?`
- `O agente deu uma resposta errada. O que faço?`
- `O Momo integra com Primavera?`
- `Era fixe terem integração com Primavera.`
- `Sim, envia essa sugestão para a equipa.`
- `Cria um ticket para eu falar com alguém.`

Expected escalation behaviour:

- A capability question or casual feature suggestion does not create a ticket automatically.
- Momo Support offers team review when the capability is unconfirmed.
- After the client explicitly confirms, the ticket is created.
- An explicit ticket/human request creates a ticket immediately.
- Security/privacy issues remain high-priority escalations.
- General documented billing questions are answered directly instead of automatically creating a ticket.
