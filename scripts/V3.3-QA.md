# Momo v3.3 - Hybrid Knowledge Retrieval QA

Goal: make direct factual questions reliably retrieve the matching approved Momo Sales knowledge entry.

## Regression questions

Run each in the real Momo Sales chat after deploy:

1. `Quanto tempo guardam logs técnicos?`
   - Must state: normal application logs use a 30-day reference retention period.
2. `E os registos relacionados com incidentes de segurança?`
   - Must state: security-incident records may be retained for up to 12 months.
3. `Garantem 100% de disponibilidade do serviço?`
   - Must state both sides: no 100% uptime guarantee; under normal conditions Momo is designed to operate 24/7.
4. `Quanto tempo guardam leads?`
   - Must retain the approved lifecycle wording for new/contacted vs lost/converted leads.
5. `Os meus dados ficam separados dos dados de outras empresas?`
   - Must state that users from other customer organizations do not have Portal access to this organization's data.

## Retrieval behavior

v3.3 searches the current user question independently instead of blending unrelated prior user questions into the embedding. It also ranks exact lexical matches across approved Sales knowledge titles, categories and content, then merges those results ahead of semantic matches.

No Supabase migration is required for v3.3. The v3.2 knowledge entries must already have been applied and reindexed.
