# Momo v2.28 - Admin-controlled primary language

## Install
No SQL migration is required. Apply the complete `app`, `lib` and `scripts` directories from the release ZIP. Run:

```powershell
node scripts/test-v228-primary-language.mjs
node scripts/test-v221-language-policy.mjs
npm run lint
npx tsc --noEmit
npm run build
```

Deploy only after lint, TypeScript and build pass.

## Manual QA using a disposable organization

1. Log in as an **Owner** of a Portuguese organization. In **Company**, verify that Primary language is displayed as Portuguese without a select or editable form field. Save other company settings. Language must remain unchanged.
2. Verify server authorization: submit `primaryLanguage=en` with the Company update action using developer tools. The backend must ignore this field. Confirm the organization and single-language agent still use Portuguese.
3. In Company, click **Pedir alteração para English**. Confirm an `account` ticket is created in the same organization with current and requested languages, and appears in Admin Support. The organization and agent should still be Portuguese.
4. Click the request button again. Verify the existing open ticket is shown instead of a duplicate. Confirm the new-ticket notification is attempted for the first ticket only.
5. As a **Member**, verify that you cannot edit Company details or call the Owner-only request action. You should still be able to create ordinary Support tickets.
6. Ask Momo Support "Como altero o idioma principal?". It should explain the Company ticket procedure without changing the language or creating a ticket automatically. Ask "Quero que mudem o idioma principal para inglês". Momo Support should submit an `account` ticket if the requested language is clear and describe team review.
7. In Momo Admin, change the primary language on a disposable **base-plan** organization to English. Check that its single supported chat language follows the new primary language.
8. In Momo Admin, change the primary language on a disposable **multilingual** organization. Ensure `supported_languages` retains its approved multiple languages.
9. With an English-primary organization, repeat the Company button and Momo Support checks in English. Check that Portuguese and English interfaces are consistent.

Do not use production client data for destructive or cross-account access tests.
