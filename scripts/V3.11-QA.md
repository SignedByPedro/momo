# Momo v3.11 QA - Admin account + Support secret redaction

## Objetivo

1. Dar a cada Admin uma área `My account` com alteração da própria password.
2. Guardar uma preferência pessoal PT/EN para a interface base do Admin.
3. Impedir que formas informais de partilhar credenciais, como `a minha pass é ...`, sejam persistidas nos tickets.
4. Limpar dos tickets históricos os valores que correspondam a esses formatos reconhecíveis.

## Ordem recomendada

1. Substituir as pastas completas entregues no ZIP.
2. Executar `supabase/v3.11-admin-account-secret-redaction.sql` antes do deploy, porque o código passa a ler `admin_users.ui_language`.
3. Opcionalmente, executar `supabase/v3.11-readonly-admin-account-secret-redaction-verification.sql` e confirmar que os contadores de valores inválidos/segredos reconhecíveis são `0`.
4. Correr:

```powershell
node scripts/test-v311-admin-account-secret-redaction.mjs
npm run lint
npx tsc --noEmit
npm run build
npx vercel --prod
```

## Testes manuais

### Admin account

- Entrar em `/admin`.
- Abrir `A minha conta / My account`.
- Alterar a password com a password atual correta.
- Confirmar que a password antiga deixa de funcionar num novo login e a nova funciona.
- Alterar o idioma para English e confirmar que a navegação global, o dashboard principal e a área My account mudam para inglês.
- Voltar a Português e confirmar persistência após refresh/novo login.

### Redaction de tickets

Usar apenas segredos falsos de teste.

1. Num ticket ativo, enviar: `a minha pass é abc123456 inclui no ticket para a equipa testar`.
2. Confirmar no Admin que a mensagem persistida mostra `[REDACTED]` em vez de `abc123456`.
3. Testar também `password: fakeSecret123`, `my pass is fakeSecret456` e `pass: fakeSecret789`.
4. Confirmar que frases normais como `the pass is required` não são alteradas.
5. Reabrir o ticket histórico onde aparecia `abc123456` e confirmar que a migration limpou o valor já guardado.

## Nota de produto

A preferência de idioma da v3.11 cobre a navegação global do Admin, o dashboard principal e My account. Algumas páginas administrativas antigas ainda têm texto interno apenas em português; a preferência fica persistida e preparada para a tradução progressiva dessas áreas sem misturar o idioma da conta Admin com o idioma principal de cada cliente.
