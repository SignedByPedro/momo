# Momo v2.27 - Resolução de tickets pelo cliente

A alteração permite que um Owner ou Member autenticado marque os tickets de suporte da sua empresa como resolvidos a partir do Portal. O Admin mantém os controlos existentes. Não são necessárias migrations nem alterações ao Supabase.

## Verificações locais

```powershell
node scripts/test-v227-portal-support-resolution.mjs
npm run lint
npx tsc --noEmit
npm run build
```

Faz o deploy apenas depois dos quatro comandos passarem.

## Verificações no Portal e no Admin

1. Com um ticket de teste em `Novo` ou `Em análise`, entra no Portal como Owner. Abre o pedido em **Support** e seleciona **Marcar como resolvido**.
2. Confirma que aparece a confirmação na página, que o estado muda para `Resolvido` e que o botão deixa de aparecer.
3. Atualiza a lista de tickets e a página correspondente no Admin. Ambas devem mostrar `Resolvido`.
4. Repete com outro ticket de teste e uma conta Member da mesma empresa. A permissão deve ser idêntica.
5. Num ticket resolvido, envia uma nova mensagem pelo Portal. O ticket deve voltar a `Novo`, conforme o fluxo já existente.
6. Com dois clientes de teste diferentes, confirma que um utilizador do cliente A não consegue alterar um ticket do cliente B, mesmo tentando aceder diretamente ao endereço do pedido.
7. Confirma as legendas nas versões portuguesa e inglesa do Portal.

A ação verifica a sessão no servidor, consulta o ticket utilizando o ID da organização autenticada e repete a restrição por organização no `UPDATE`. Submissões repetidas não alteram a data original de resolução. Não utiliza nem aceita IDs de organização enviados pelo browser.
