# Momo v3.24 - Admin Owner invites from My Account

## Objetivo
Substituir o registo Admin protegido por código por um fluxo invite-only gerido por Owners existentes dentro de Admin > My Account.

## Fluxo esperado
1. Um Owner autenticado abre `/admin/account`.
2. Em **Admin access**, introduz o email do novo Owner e envia o convite.
3. O Supabase envia o email de convite para `/admin/accept-invite`.
4. O destinatário confirma o email e é encaminhado para `/admin/setup-password`.
5. Define uma password com pelo menos 8 caracteres.
6. Entra no Admin com role `owner`.
7. O novo Owner aparece na lista de Owners em My Account.

## Segurança
- O server action valida `session.role === "owner"`.
- Não existe registo Admin público funcional em `/admin/register`.
- `MOMO_ADMIN_INVITE_CODE` deixa de ser usado.
- Se a criação da entrada em `admin_users` falhar, o Auth user convidado é removido.
- A criação da password exige email confirmado e uma entrada `admin_users` com role `owner`.

## Configuração Supabase
Garantir que o URL de produção permite o redirect:

`https://<dominio-do-momo>/admin/accept-invite`

Se estiveres a usar `NEXT_PUBLIC_APP_URL`, esse domínio é usado automaticamente no convite.
