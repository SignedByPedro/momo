# Momo v2.24 - Team access and personal account deletion

Run **supabase/v2.24-guarded-membership-revocation.sql** before deploying. Then run the read-only `supabase/v2.24-readonly-guarded-membership-verification.sql` and confirm: `true, false, false, false, true`.

Local checks:

```powershell
node scripts/test-v224-account-access.mjs
npm run lint
npx tsc --noEmit
npm run build
```

Manual smoke tests in a **test organisation only** (personal deletion is irreversible):

1. Log in as a client Owner. Visit Portal > Team, remove a test Member and verify that member can no longer sign in. Confirm that removing another Owner is not offered, only a support link.
2. Sign in as Member and verify that My account is visible. Use an incorrect password first and confirm no deletion occurs. With a separate disposable member account, confirm the typed DELETE/ELIMINAR prompt and delete. Confirm the account can no longer sign in and that organisation data remains.
3. With two accepted test Owners, use a disposable Owner to delete its **own** account. Verify the other Owner remains, can access the Portal, and the widget and data still work.
4. With the last active Owner, open My account. Confirm direct deletion is unavailable, and that submitting the form creates a high-priority Privacy ticket without deleting the organisation or the Owner's account.
5. In Momo Admin, attempt to revoke the last accepted Owner. Verify it is blocked. Add and confirm another Owner, then remove the original Owner and verify access is gone.
6. On a cancelled organisation, check that My account still opens and support is available. The sole-Owner transfer safeguard must still apply.
7. For simulated Auth deletion failures (e.g. a test user owning Storage objects), confirm the attempted membership is restored and a user-visible error is shown. Check server logs if restoration itself fails.

**Important:** Account deletion removes the Supabase Auth user and its organisation membership, but does not delete the company or its operational history. Requests to erase remaining personal data are handled through the existing Privacy process.
